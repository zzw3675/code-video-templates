# 用代码做知识视频：标准模板

> 来源：观看抖音、哔哩哔哩上 Vibe 知识大赛的相关知识视频后，蒸馏总结出来的经验（原稿《用代码做知识视频的经验总结》，2026-10-31）。
> 定位：不是讲稿，不是成片，是每期开工前直接套用的标准模板。
> 一句话原则：**质感是皮，讲解是骨——观众看完要能讲得出“因为……所以……”。**

## 怎么用

1. 先读 `STANDARD.md`：全片硬规矩，一共 8 条，违反任何一条都算未达标。
2. 每镜按 `templates/` 里对应的模板填空：先定这镜是哪个类型，再填字段，最后过 `checklist.md`。
3. 先做 30 秒样片，样片过了再铺全片；每镜截图过三问，至少改两轮再交片。

## 目录

| 文件 | 用途 |
| --- | --- |
| `STANDARD.md` | 全片硬规矩：视觉、颜色、字幕、节奏、结尾、交片 |
| `templates/01-opening.md` | 开场：生活场景 / 反差数字，前 3 秒不出术语 |
| `templates/02-growing-scene.md` | 主视觉生长：一个画面撑两句以上，内部生长不硬切 |
| `templates/03-number-visuals.md` | 数字可视化：数轴、竖条仪表、点阵、概率地图、尺度条、元素格 |
| `templates/04-formula.md` | 公式拆解：原文 + 符号标注 + 口语意译 |
| `templates/05-chapter-evidence.md` | 章节与考据标签：章节号、年份、人物、地点、尺度单位常驻边缘 |
| `templates/06-ending-poster.md` | 结尾海报：一句情绪话 + 标题卡，回扣开头 |
| `checklist.md` | 样片门禁 + 每镜三问 + 交片清单 |

## 全片视觉基线

- 深色底 + 辉光线稿 + 金色关键词。
- 颜色全片一个意思，见 `STANDARD.md` 第 2 条。
- 每帧至少 4 层（章节号 + 主图 + 标注或数字 + 字幕），好的帧做到 6–10 层。
- 任何一刻只有一个主体在动；转场是长出来或推拉过去，不是硬切。
