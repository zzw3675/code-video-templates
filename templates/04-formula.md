# 模板 04：公式拆解三件套

## 这镜干什么

公式不能只剩符号：原文、标注、口语意译三件缺一不可。

## 填空

- 公式原文：______
- 每个符号的中英文标注：
  - ______：中文 ______ / 英文 ______
  - ______：中文 ______ / 英文 ______
  - ______：中文 ______ / 英文 ______
- 一句口语意译（不用术语讲清它在算什么）：______

## 画面层

- [ ] 公式原文（主视觉）
- [ ] 每个符号的标注（逐个点亮，不一次全亮）
- [ ] 口语意译字幕（一行一眼读完）
- [ ] 章节号常驻

## 合格标准

- [ ] 符号逐个标注，不是一次性贴满
- [ ] 意译是口语，不是把公式再念一遍
- [ ] 任何一刻只有一个主体在动

## 反例（不要这样做）

- 公式只剩符号，没有标注、没有意译
- 标注一次全出，观众不知道先看哪
