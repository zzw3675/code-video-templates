# 模板 02：主视觉生长（一镜撑两句以上）

## 这镜干什么

一个主视觉长停留十几秒，靠内部生长推进，不靠硬切换画面。

## 填空

- 主视觉（叫得出名字的东西）：______
- 这镜要讲的结论（一句话）：______
- 讲哪两句以上（每句只改一处）：
  1. ______ → 画面变化：______
  2. ______ → 画面变化：______
  3. ______ → 画面变化：______（如有）
- 景别路线：全 → 中 → 近（同一固定画面不撑过三四句）

## 生长方式（每 3–5 秒至少一种）

- [ ] 长一根分支（如概率树）
- [ ] 光点移动
- [ ] 条形伸长
- [ ] 格子点亮
- [ ] 旧层变灰退后

## 合格标准

- [ ] 一个画面撑两句以上，每句只改一处
- [ ] 任何一刻只有一个主体在动
- [ ] 转场是长出来或推拉过去，不是硬切
- [ ] 字幕出现 0.3 秒内屏上有动作

## 反例（不要这样做）

- 句句切画面，景别不变
- 一个画面从头到尾一动不动，只换字幕
- 示意图只有色块加一行字
