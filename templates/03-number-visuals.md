# 模板 03：数字可视化（关键数字要大、要动、要会变）

## 这镜干什么

关键数字放在视觉重心，用一种仪表让它伸长、点亮、打叉，而不是静态贴图。

## 先选一种仪表（每镜只选一种，别堆）

- [ ] 数轴
- [ ] 竖条仪表
- [ ] 点阵
- [ ] 概率地图
- [ ] 尺度条
- [ ] 元素格

## 填空

- 关键数字：______（结论 / 大数字 → 金色）
- 数字从 ______ 变到 ______，变化靠什么动作：______
- 过程部分（青蓝）：______
- 错的部分（红色，打叉 / 否定）：______
- 退后的旧层（灰色）：______

## 合格标准

- [ ] 数字是画面重心，一眼能看见
- [ ] 数字会动：伸长、点亮、打叉，至少一种
- [ ] 每句关键结论都配一个数字、一个仪表或一张图
- [ ] 颜色按 STANDARD.md 第 2 条，不乱用

## 反例（不要这样做）

- 数字只是一张静态贴图
- 一屏堆多种仪表，看不出哪个是主角
- 大数字和结论句颜色不一致
