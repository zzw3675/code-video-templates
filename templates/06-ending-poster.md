# 模板 06：结尾海报（回扣开头，单帧能传播）

## 这镜干什么

不是普通总结，是一张能截图传播的海报：情绪话 + 标题卡，回扣开头。

## 填空

- 一句情绪话：______
- 标题卡文字：______
- 回扣开头的点（开场那个场景 / 数字）：______
- 截图检查：单帧截图，不看前后文，能看懂吗？______

## 合格标准

- [ ] 有情绪话，不只是“今天就讲到这里”
- [ ] 有标题卡，画面定格能当封面 / 截图用
- [ ] 回扣开头，首尾呼应
- [ ] 字幕区干净，一镜最多一条小字

## 反例（不要这样做）

- 结尾只是把要点再念一遍
- 结尾画面杂乱，截图没法单独传播
