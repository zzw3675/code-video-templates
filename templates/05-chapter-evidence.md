# 模板 05：章节与考据标签（常驻边缘，不占主视觉）

## 这镜干什么

让观众随时知道：讲到哪、谁说的、多大。标签常驻画面边缘，不抢主视觉。

## 填空（有哪项填哪项，没有就空着，别编）

- 章节号：______
- 年份：______
- 人物：______
- 地点：______
- 尺度单位：______

## 画面要求

- [ ] 标签在画面边缘常驻，不随主视觉生长而消失
- [ ] 标签区干净，主视觉不动标签
- [ ] 一镜最多一条小字（标签不算正文，不挤字幕区）

## 合格标准

- [ ] 任意一帧暂停，都能说出讲到哪一章
- [ ] 年份 / 人物 / 地点 / 尺度有出处才写，没出处宁可空着
